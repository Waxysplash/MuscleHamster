## Overview

This release addresses bugs discovered in v1.0.2 and introduces app-wide themed alerts that match the warm color scheme.

---

## Bug Fixes

### 1. Notification Toggle Not Working

**Problem:** When users enabled notifications, the toggle would stay ON even if they denied the permission prompt in iOS settings.

**Fix:** Updated `handleUserEnabledChange()` in `NotificationSettingsScreen.js` to:
- Check the return value of `enableNotifications()` before updating state
- Reset toggle to OFF if permission is denied
- Properly sync state with actual permission status

**File Changed:** `src/screens/Settings/NotificationSettingsScreen.js`

---

### 2. PendingRequestsScreen Wrong Color Scheme

**Problem:** The Pending Friend Requests screen had white/black/grey iOS default colors instead of the app's warm cream/brown theme.

**Fix:** Updated all colors to match the app theme:
- Header background: `#fff` → `#FFF8F0` (cream)
- Title color: added `#4A3728` (dark brown)
- Tab container: `#E5E5EA` → `rgba(139, 90, 43, 0.12)` (warm brown tint)
- Tab text colors: updated to match theme
- Request names, empty state text: updated to `#4A3728`

**File Changed:** `src/screens/Social/PendingRequestsScreen.js`

---

### 3. Friend Request Error Handling

**Problem:** When friend request permissions failed in Firestore, users saw generic error messages that weren't helpful.

**Fix:** Added better error handling in `FriendService.js`:
- Detects permission-denied errors specifically
- Shows user-friendly message: "Unable to send friend request. Please try signing out and back in."
- Applied to both `useInviteCode()` and `sendFriendRequest()` functions

**File Changed:** `src/services/FriendService.js`

---

## New Feature: Themed Alerts (App-Wide)

**Problem:** Native iOS/Android alerts were grey bubbles that didn't match the app's warm, cozy color scheme.

**Solution:** Created a custom themed alert system that replaces ALL native `Alert.alert()` calls across the entire app.

### New Components Created

#### `ThemedAlert.js`
Custom alert modal component with:
- Cream background (`#FFF8F0`)
- Dark brown text (`#4A3728`)
- Semi-transparent brown overlay (`rgba(74, 55, 40, 0.5)`)
- Orange primary buttons (`#FF9500`)
- Brown secondary buttons (`#8B5A2B`)
- Rounded corners and smooth animations

**File:** `src/components/ThemedAlert.js`

#### `AlertContext.js`
Global React context for showing alerts from any screen:
- `showAlert(title, message, buttons)` function
- Manages alert visibility state
- Renders single ThemedAlert at app root level

**File:** `src/context/AlertContext.js`

### App.js Integration
- Added `AlertProvider` wrapper around the app
- Themed alerts now available globally via `useAlert()` hook

**File:** `App.js`
